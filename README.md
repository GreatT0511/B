## 設計の中核

- テーマ（台本指定）: **個人の効率化から、組織の資産化へ** — 「使える」から「残して渡せる」へ
- ビジョン: タスクの言語化（知識×スキルズ）→ ポートフォリオ化 → データの循環 → **生成AIが読める組織（校務タスクのエージェント化＝いつ誰が担当になってもできる）**
- ワーク1「振り返る」の付箋を言語化の素材にし、「AIに渡せなかったもの」をワーク3「伸ばす」（資質能力）への橋にする

## 当日の環境前提

- 会場ネットワークは期待しない。**ワークは模造紙＋付箋で完結**（ワーク2用模造紙は事務局へ追加手配）
- 講師デモは個人回線（テザリング）＋画面録画のバックアップ
- 参加者のAI確認は任意・個人回線。特定製品に依存せず、**knowledge／skillsの2ファイルをアップロードして挙動確認**する型で統一（Gemini／Copilot／ChatGPTいずれも同じ操作）
